# Pro.Hibited — portail créatif

Portail de Benoît Lubert réunissant les jeux Pro.Hibited, les univers Blacklace, Feuch Lab, Le Bazar du Feuch et les romans.

## Structure

- `dist/index.html` : site statique complet, prêt à être ouvert ou hébergé.
- `.openai/hosting.json` : configuration du site actuellement hébergé avec ChatGPT Sites.

## Prévisualiser

Ouvrir `dist/index.html` dans un navigateur, ou héberger le dossier `dist/` comme site statique.

## Version en ligne

https://prohibited-universe-2026.fairy-frog-8671.chatgpt.site

Les liens internes vers les projets renvoient aux pages jouables hébergées séparément.
